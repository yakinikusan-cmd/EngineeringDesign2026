# エンジニアリングデザイン2026(名称未定)
# システム概要
自動で動くこっくりさんを作成する。

ロボット上面にARマーカーを配置し、カメラからそれを認識し、ロボットの位置を推定する。

ロボットに無線で接続されたPCで文字を入力すると質問を投げかけると、返答に応じて、ロボットが50音表の上を走り回る。
返答の作成には事前に返答パターンを作成しておく。

## 送信側ラズパイ
送信側ラズパイではカメラから画像を受け取り、open cvでARマーカの位置と向きを認識し、その情報をUDP通信で受信側PCへ送信する。
## 受信側ラズパイ
受信側ラズパイではリモートデスクトップで接続されたPCから質問を入力し、返答を考える。送信側ラズパイから受け取った自己位置と返答から出る目標位置の距離の差と角度の差からモーターへの出力を計算し、目的地へ移動する。目的地と自己位置の差が閾値より小さくなれば返答の文字へ移動したと認識し、次の文字へと移動する。

```(mermaid)
    flowchart LR
        subgraph 送信側
            A[カメラ] --> B[Raspberry Pi]
        end

        B -->|UDP| C

        subgraph 受信側
            C[Raspberry Pi] --> D[モーター]
        end
```

```(mermaid)
    flowchart LR
        A[スマートフォン<br/>DroidCam] -->|Wi-Fi / 映像通信| B[Raspberry Pi]
        B -->|モーター制御| C[モータードライバ]
        C --> D[モーター]
```

# イチオシなところ
ロボットが自分の位置を認識し、決められた目的地へ移動すること。

どんな返答が返ってくるか見た人がわくわくして楽しめるところ。
